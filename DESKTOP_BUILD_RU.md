# Serega V3 — Windows EXE

Этот проект упаковывает игру в настольное приложение Electron: окно Windows, локальный HTTP/WebSocket-сервер, Three.js и GLB-модель перчаток входят в проект. Установщик создаёт ярлыки в меню «Пуск» и на рабочем столе.

## Сборка установщика на Windows

Требуется Windows 10/11 x64, Node.js 20 LTS или новее и интернет на первом запуске сборки (для скачивания npm-зависимостей и Electron).

1. Распакуй архив в обычную папку, например `C:\Games\SeregaV3`.
2. Установи Node.js LTS: https://nodejs.org/
3. Открой папку проекта в Проводнике.
4. Щёлкни правой кнопкой по `scripts\build-windows.ps1` и запусти PowerShell-скрипт. Если политика Windows запрещает скрипт, открой PowerShell в папке проекта и выполни: `powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1`.
5. После успешной сборки установщик появится в `release\Serega-V3-Setup-1.1.0.exe`.

Альтернатива — открыть терминал в папке проекта и выполнить:

```powershell
npm install
npm run check
npm run dist:win
```

Для запуска без установщика: `npm run desktop` после `npm install`.

## Важные ограничения

- Приложение поднимает игровой сервер на этом ПК и подключается к нему через loopback-интерфейс. Это работает локально; для игры с друзьями через интернет нужен постоянно доступный удалённый сервер и отдельная настройка адреса подключения. Не отправляй друзьям ссылку `127.0.0.1` — она указывает на их собственный компьютер.
- Первый `npm install` и упаковка требуют интернет, поскольку Electron загружается отдельно.
- Перед публичным релизом нужны реальные тесты на Windows (разные видеокарты, разрешения, запуск без сети, антивирусы, несколько игроков, нагрузка и длительная сессия). Нельзя честно гарантировать «вообще без ошибок» без этих проверок.
